#wansom AI - Enterprise Legal Intelligence for East Africa
wansom AI is the premier legal technology platform purpose-built for the East African legal ecosystem. We empower advocates, in-house counsels, and law firms across Kenya, Tanzania, Uganda, and Rwanda with a high-architecture, secure, and intelligent platform designed to streamline complex legal workflows.

## 🚀 Key Features

- **Legal AI Engine**: Advanced natural language research with streaming responses and statutory citations for East African law.
- **Judicial Analytics**: Strategic litigation insights with judge performance profiles, win rates, and citation analysis.
- **Agentic Mentorship (Amani)**: AI-powered professional development through simulated practice sessions, cross-examination drills, and Socratic tutoring.
- **Specialist Marketplace**: Access to domain-specific AI agents (Conveyancing, Commercial, Family Law) or build your own custom specialists.
- **Files & Document Vault**: Secure, folder-organized document management with metadata insights and cloud-ready storage.
- **Enterprise Integrations**: Seamless connections with Google Calendar, Gmail, and leading Document Management Systems.

## 🏗️ High-Architecture Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion.
- **Backend Service**: Multi-model AI Proxy orchestrating **DeepSeek**, **PageIndex**, and **Google Agent Kit**.
- **Identity**: Firebase Authentication for secure, enterprise-grade access management.
- **Data Layer**: Supabase (PostgreSQL) for persistent storage and Row Level Security (RLS).

## 🏁 Development Setup

1.  **Clone the Repository**
2.  **Install Dependencies**:
    ```bash
    npm install
    ```
3.  **Environment Configuration**:
    Configure your `.env` file with the necessary Firebase and Service keys (refer to `DOCUMENTATION.md`).
4.  **Run Development Server**:
    ```bash
    npm run dev
    ```

## 🔒 Security & Compliance

Lawlify AI is designed for the high-security requirements of legal practice:
- **Zero-Exposure AI Proxy**: All AI API keys are mediated through the backend service.
- **Encryption**: End-to-end data encryption for all client matters.
- **Compliance**: Designed to align with GDPR and local Data Protection Acts in East Africa.
